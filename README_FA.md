# پنل اینترنتی کنترل ESP32-CAM

این پروژه یک سایت واکنش‌گرا با ورود رمزدار می‌سازد و فرمان‌ها را از سمت سرور به EMQX می‌فرستد. رمز MQTT در مرورگر نمایش داده نمی‌شود.

## ۱) آماده‌سازی فایل‌ها
محتویات ZIP را در یک پوشه استخراج کن. فایل `.env.example` را فقط برای راهنمایی نگه دار؛ مقادیر آن را در بخش Environment سرویس میزبانی وارد کن. فایل `.env` را در GitHub بارگذاری نکن.

## ۲) ساخت مخزن GitHub
یک Repository جدید بساز و تمام فایل‌های این پروژه (از جمله پوشه public) را بارگذاری کن. فایل `.env` و رمزها را هرگز در مخزن قرار نده.

## ۳) ساخت سرویس در Render
1. در Render ثبت‌نام کن و GitHub را متصل کن.
2. New + → Web Service را بزن و همین Repository را انتخاب کن.
3. Runtime: Node
4. Build Command: `npm install`
5. Start Command: `npm start`
6. در بخش Environment این متغیرها را اضافه کن:
   - `MQTT_HOST` = `l1a5b2a0.ala.eu-central-1.emqxsl.com`
   - `MQTT_USERNAME` = `esp32cam`
   - `MQTT_PASSWORD` = رمز کاربر MQTT با نام esp32cam در EMQX (نه رمز ورود حساب سایت EMQX)
   - `CONTROL_PASSWORD` = یک رمز جدید و قوی که فقط برای ورود به سایت کنترل استفاده می‌کنی
   - `SESSION_SECRET` = یک رشته تصادفی طولانی و غیرقابل حدس (حداقل 32 کاراکتر)
   - `NODE_ENV` = `production`
7. برای هر متغیر روی Save Changes بزن و سرویس را Deploy کن.
8. پس از Deploy موفق، Render یک نشانی HTTPS شبیه `https://your-service.onrender.com` می‌دهد. آن نشانی سایت کنترل تو است.

## ۴) استفاده
- سایت را با گوشی دوم و اینترنت 4G باز کن.
- رمز `CONTROL_PASSWORD` را وارد کن.
- وضعیت اتصال EMQX و ESP32 و چهار رله را می‌بینی.
- برای هر رله دکمه روشن یا خاموش را بزن.

## ۵) تنظیمات لازم در ESP32
کد ESP32 باید این Topicها را استفاده کند:
- دریافت فرمان رله ۱ تا ۴: `home/esp32/relay/1/set` تا `home/esp32/relay/4/set`
- انتشار وضعیت: `home/esp32/relay/state` با JSON مثل `{"relay1":false,"relay2":true,"relay3":false,"relay4":false}`
- انتشار وضعیت دستگاه: `home/esp32/status` با `ONLINE` و LWT برابر `OFFLINE`

این موارد مطابق نسخه کدی است که در گفت‌وگو آماده شد.

## نکات مهم
- آدرس `192.168.x.x` آدرس محلی است؛ آدرس عمومی پنل را Render می‌دهد.
- رمز MQTT را در HTML یا GitHub قرار نده.
- پلن رایگان Render ممکن است بعد از مدتی بی‌استفاده ماندن سرویس را متوقف کند و اولین بازدید بعدی با تأخیر باز شود؛ شرایط پلن رایگان ممکن است تغییر کند.
- برای اجرای ۲۴ ساعته بدون خواب، باید پلنی انتخاب شود که سرویس را متوقف نکند.
- این پنل فقط از طریق HTTPS ارائه‌شده توسط Render استفاده شود.
- هیچ بار الکتریکی خطرناک یا برق شهر را بدون رله ایزوله مناسب، جعبه ایمن و نظارت فرد متخصص متصل نکن.
